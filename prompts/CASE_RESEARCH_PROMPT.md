# CASE RESEARCH PROMPT

Build the NUSANTARA real-world case library.

## Target

Minimum **100 validated Indonesian cases**.

## Requirements

- use multiple decades where useful
- geographic diversity
- category diversity
- official primary sources where possible
- reputable news for chronology/public response when needed
- no copied article text
- explicit fact vs simulation separation
- timeline
- causal chain
- decision window
- consequence possibilities
- source provenance

## Deliverables

For each case:

- structured record
- source list
- validation status
- geographic tags
- category tags
- timeline
- causal chain
- game adaptation notes

Also generate:

`research/reports/CASE_LIBRARY_COVERAGE_REPORT.md`

with counts by:

- province
- island group
- category
- year/decade
- validation status
- source quality

Do not stop at the first 100 if there are many high-quality candidates, but do not lower quality just to increase count.
