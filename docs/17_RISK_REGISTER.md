# 17 RISK REGISTER

| Risk | Severity | Mitigation |
|---|---|---|
| Scope explosion | High | Scope firewall, staged MVP |
| Dataset inconsistency | High | provenance, definitions, validation |
| Missing district-level data | High | preserve resolution, gap registry |
| GIS performance | High | geometry simplification, decoupled rendering |
| 514-region simulation cost | High | compact state arrays/structures, benchmark early |
| Cultural misrepresentation | High | source review, sensitivity flags, no stereotypes |
| Political sensitivity | High | fictional protagonist, factual case framing, no partisan persuasion |
| AI compliance | High | usage log, human review, source evidence |
| Copyright/licensing | High | source/license register, paraphrase text, approved assets |
| Scraper breakage | Medium | caching, tests, source adapters |
| Website rate limits | Medium | throttling/backoff, APIs first |
| Data staleness | Medium | snapshot metadata, latest-available logic |
| Save corruption | Medium | atomic writes, versioning, backups |
| Android memory/performance | High | benchmark on target hardware, no unnecessary nodes |
| APK size | Medium | compressed assets, avoid oversized media |
| Overly academic UX | Medium | progressive disclosure, tutorialized cases |
| Too much randomness | Medium | controlled uncertainty, explainable factors |
| Case repetition | Medium | eligibility rules, cooldowns, branching |
| Resource model too complex | High | start with core variables, causal review |
