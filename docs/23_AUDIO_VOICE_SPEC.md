# 23 AUDIO AND VOICE SPECIFICATION

## Goal

Use audio to reinforce state, consequence, and character rather than add noise.

## Audio layers

- main theme
- calm management loop
- crisis theme
- decision confirmation
- consequence feedback
- positive/negative sentiment feedback
- ambient regional cues when justified
- character voice

## Music generation

Generated music is permitted within the competition rules but must be logged and licensing/usage terms verified.

## Character voice

AI TTS can be used for Nara and advisors. Keep the same voice identity across a run.

## Audio design rule

Do not use loud or repetitive sounds that punish the player for reading data slowly.

## Compression

The primary target is Windows desktop. Keep audio assets compact enough for fast startup and reasonable download size, but do not distort the audio design solely to satisfy a mobile size budget. If an APK remains a mandatory competition deliverable, perform a separate compression pass for the Android package later.
