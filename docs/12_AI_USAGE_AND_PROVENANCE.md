# 12 AI USAGE AND PROVENANCE

## Competition requirement

The IT-CAS guidebook allows AI/Generative AI as an assistive tool while requiring substantive disclosure and continued human responsibility for originality, quality, legality, and the development process.

## AI tools currently planned

- Claude Code: engineering, automation, debugging, data pipeline assistance
- ChatGPT: research strategy, game design, verification, drafting, analysis
- GPT-based image/asset assistance: visual ideation/generation as actually used
- Lyria family: music/audio generation as actually used
- AI TTS/voice generation: character voice as actually used
- Figma: non-AI design/prototyping workflow unless AI features are actually used

Do not claim use of a tool that was not actually used.

## AI usage log

Maintain `research/reports/AI_USAGE_LOG.md` or equivalent with:

```text
date
tool
purpose
input type
output type
human modification
final usage
license/terms checked
evidence path
```

## Creative responsibility

Human team members must provide substantive creative direction, review, selection, modification, integration, testing, and final approval.

## Data provenance

AI-generated factual claims are not evidence. The source remains the official/public source.

## Asset provenance

For each final asset, record:

- asset name
- creator/tool
- source
- generation method
- human modification
- license/usage status
- final location

## Copyright rule

Do not generate or use assets that imitate a living artist's identifiable style, copyrighted game character, branded identity, or protected content in a way that creates infringement risk.

## Historical/news text

Do not paste articles into game content. Create concise original paraphrases and cite the source.
