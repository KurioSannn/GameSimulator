## Rules
- The runner fails a test on any engine or script error (`OS.add_logger`), and fails a whole suite that cannot be parsed. It never hangs (regression 2026-10-06).
- Hazard-free worlds (`flood_frequency = 0`) are used when a test isolates a non-hazard mechanism. Hazard behaviour has its own tests.
- Test fixtures (e.g. a food-deficit world, a "BIG" commitment policy) are explicit, local to the test, and never written to `game/data`.
- Golden master `game/tests/golden/case0001.json`: regenerate only deliberately (`NUSANTARA_UPDATE_GOLDEN=1`) and state the reason in the commit.
- Every simulation bug found gets a regression test where technically appropriate. The bug list lives in the milestone reports.
- Each case suite loads only its own case family, so golden masters stay independent (D-044).
