# 18 GLOSSARY

## Baseline

Starting value derived from the latest selected official data snapshot.

## Real data

Data directly supported by a source.

## Derived data

A value calculated from one or more sourced values using documented transformations.

## Simulated data

A value created by the game simulation after player actions and time progression.

## Reference data

Factual information used for context but not necessarily changed by gameplay.

## Tick

One internal simulation time step. Baseline: one month.

## Turn

One player-facing major time block. Baseline: one quarter.

## Region

An administrative entity represented by the game simulation. Primary interactive target: province or regency/city.

## Natural capital

A natural asset or ecological stock/potential that contributes to long-term state or production.

## Production resource

A flow or output generated over time.

## Capacity

The ability to produce, distribute, or provide services.

## Case

A real-world event/problem adapted into a game decision situation.

## Event

A game runtime occurrence, which may be driven by a case, simulation condition, or internal system.

## Stakeholder

A group or institution affected by policy or involved in implementation.

## Sentiment

Simulated public response based on current and historical conditions.

## Causal chain

A sequence where one state change creates another state change.

## Snapshot

A versioned collection of source data used as a game baseline.

## Provenance

Metadata showing where a fact/value came from and how it was transformed.

## Data resolution

The geographic level at which a dataset is actually measured or published.

## Cultural sensitivity

A classification indicating whether cultural material is appropriate for direct gameplay adaptation.
