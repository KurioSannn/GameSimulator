# Aset antarmuka NUSANTARA

Sumber: file Figma milik proyek, xXZj1Xnoxln1coG2yEO81a, diekspor pada 15 November 2026 melalui konteks desain resmi.

- slots.json memetakan nama lapisan dari konteks Figma ke berkas lokal. Tidak ada URL sementara pada jalur runtime.
- Berkas gambar/SVG dipertahankan tanpa menggambar ulang atau merasterisasi layar. Lima respons dengan akhiran PNG ternyata berformat JPEG; hanya ekstensi lokal yang diperbaiki. Pemotongan potret menggunakan AtlasTexture mengikuti image fill Figma.
- Peta dan grafik di prototipe berisi ilustrasi/nilai contoh. Runtime memakai mesh GIS lengkap 514 kabupaten/kota dan nilai simulasi, termasuk pada peta kecil kasus/laporan.
- Font Lilita One dan Inter berada di assets/fonts/ bersama lisensi SIL Open Font License masing-masing. Sumber: repositori resmi [Google Fonts](https://github.com/google/fonts).
- Pencatatan ukuran, format dan SHA-256 ada di manifest.json. Pengujian slot dan geometri aset yang terlihat ada di laporan ui_runtime_20261115/flow/qa_ui.json.

Penggunaan aset tetap mengikuti hak dan persetujuan tim atas file Figma asal. Tidak ada aset atau karakter baru yang dihasilkan pada fase integrasi ini.
